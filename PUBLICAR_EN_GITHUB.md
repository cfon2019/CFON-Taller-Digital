# Publicar CFON Taller Digital en GitHub Pages

1. Inicia sesión en GitHub y crea un repositorio **público** llamado `CFON-Taller-Digital` con README (opcional).
2. Abre el repositorio y elige **Add file → Upload files**.
3. Extrae este ZIP y arrastra **los archivos y la carpeta `icons` de su interior**, NO la carpeta contenedora. Debe existir `index.html` en la raíz del repositorio. Confirma con **Commit changes**.
4. Abre **Settings → Pages → Build and deployment**. Elige **Deploy from a branch**, rama **main**, carpeta **/(root)** y pulsa **Save**.
5. La dirección prevista es `https://TU-USUARIO.github.io/CFON-Taller-Digital/`; sustitúyela por la dirección que GitHub Pages muestre en Settings → Pages.
6. En Chrome/Android, abre el sitio y usa el menú **Instalar aplicación** o **Añadir a pantalla principal**. En Fedora usa la opción Instalar de Chrome si está disponible.

## Privacidad, datos y modo offline
- No subas DWG/DXF, planos, documentos familiares ni archivos privados a un repositorio público. Este paquete incluye fichas, no documentos originales.
- Los proyectos creados o editados se guardan en el almacenamiento **local de cada navegador**: no se sincronizan entre Fedora y Android. Usa **Exportar datos** e **Importar datos** para trasladarlos.
- El modo sin conexión guarda la interfaz después de abrir el sitio una primera vez con Internet, sujeto a la política de almacenamiento del navegador. Los enlaces a recursos externos y partes aún no migradas requieren Internet.
- Si usas un nombre de repositorio distinto, la aplicación funciona gracias a sus rutas relativas.
